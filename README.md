# AYURWELL

AyurWell is a polished web application prototype focused on Ayurvedic wellness, diet guidance, and community interaction. The platform is designed to provide a seamless experience for patients, doctors, and administrators by combining healthcare-inspired dashboards, food insights, and a user-friendly interface.

## 🌿 Project Purpose

AyurWell aims to make Ayurvedic wellness more accessible by offering an interactive digital experience where users can:

- explore a curated food and wellness database
- understand Ayurvedic dietary concepts through a modern UI
- interact with role-based dashboards for different user types
- experience a lightweight community-style module
- enjoy a responsive and visually appealing interface

## ✨ Key Features

- Patient-focused dashboard for wellness and dietary exploration
- Doctor dashboard for viewing and managing patient-related information
- Admin panel for overseeing users and food content
- Community section for sharing and interacting with content
- Light and dark theme support
- Local browser storage for persistent demo data
- Clean and responsive design built with modern frontend tools

## 🛠️ Technology Stack

- React 18
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/Monicamathursivakumar/AYURWELL.git
cd AYURWELL
npm install
```

### Run Locally

Start the development server:

```bash
npm run dev
```

Then open the local URL displayed in your terminal.

### Build for Production

```bash
npm run build
```

## 📁 Project Structure

- src/components - Main UI components for landing, dashboards, community, and admin views
- src/data - Food and content data used by the app
- src/utils - Helper modules for storage and analysis
- public - Static assets and public files

## 🧩 Application Flow

1. Users land on the home experience and can navigate through the app.
2. Different roles access tailored dashboards and features.
3. The app stores key data locally in the browser for a smooth demo experience.
4. Community and content sections add a more complete wellness platform feel.
